# solar-syst 🪐

> 一个**纯 HTML + CSS（零 JavaScript）**的太阳系公转动画，附带一个同样零依赖的 **CSS 404 星空页面**。
> 所有天体按**真实公转周期等比缩放**运行，开箱即用、可直接托管到 GitHub Pages。

## 项目简介

`solar-syst` 由两个相互独立的静态页面组成：

| 页面 | 说明 |
| --- | --- |
| `index.html` | 太阳系公转动画主页面：以太阳为中心，八大行星 + 冥王星 + 小行星带按真实周期比例环绕运行 |
| `404.html` | 纯 CSS 的 404 星空页面：会眨眼的星星、睡觉的月亮、扇动翅膀的 3D 小鸟 |

两个页面都**不依赖任何构建工具、框架与 JavaScript 运行时**（404 页仅有一段可选的自动跳转脚本），双击即可在浏览器打开。

## 功能总览

### 一、太阳系页面（`index.html`）

**核心特性**

- ⏱️ **真实时间比例公转**：以「地球公转一周 = 30 秒」为基准换算，各行星动画时长严格对应其真实公转周期（水星 7.19s ↔ 87.5 天，海王星 4911.78s ↔ 59802 天）。
- 🪐 **完整天体阵容**：太阳 + 水星、金星、地球、火星、木星、土星、天王星、海王星、冥王星 + 小行星带。
- 🌍 **地月系统**：地球自带一颗跟随公转的月球（`2.244s ↔ 27.32 天`）。
- 💍 **土星环**：倾斜 52° 的行星环，并反向旋转以保持环面朝向稳定。
- 🌌 **星空背景**：`radial-gradient` 深空底色 + 单个伪元素 `box-shadow` 绘制的 **300+ 颗随机星点**。
- ☄️ **小行星带**：位于火星与木星轨道之间，由数百个 `box-shadow` 点阵模拟的碎石带，独立旋转（≈6 年/圈）。
- 🔆 **光照立体感**：每颗行星使用 `inset box-shadow` 营造背光面阴影（晨昏线效果）。
- 🎨 **拟真配色**：每颗天体使用独立的渐变/实色（如木星 `#c76e2a`、天王星 `#b5e3e3`、冥王星 `#fff`）。
- ♾️ **无缝循环**：`orb` 关键帧 `rotate(0deg) → rotate(-360deg)`，`linear infinite` 匀速无缝衔接。
- 📐 **同心圆轨道**：所有天体以 `top/left: 50%` + 负 `margin` 精确定位，形成同心轨道体系。
- 🧩 **纯 CSS 驱动**：动画全部由 `@keyframes` 完成，主页面**零 JavaScript**。
- 🧱 **语义化结构**：每个天体一个 `div`，类名即天体名（`.mercury` / `.saturn` ...），便于扩展。
- 🏷️ **标题与图例面板**：左上角含标题、说明文案与九大天体图例（色点 + 名称 + 周期），悬停条目有微交互。
- 🌐 **球体光照质感**：每颗行星改用 `radial-gradient(circle at 32% 28%, …)` 高光 + 暗部，立体感更强。
- 🔆 **太阳日冕呼吸**：`sunGlow` 关键帧让光晕缓慢明暗脉动。
- 🖱️ **悬停交互**：鼠标移到任意行星上，本体放大 2.2× 并加光晕，所在轨道线同时提亮（纯 CSS 实现）。
- 📋 **悬停数据卡**：悬停任意轨道 / 天体，右下角弹出该天体的**真实数据卡**——赤道直径、质量、平均密度、表面重力、公转 / 自转周期、轨道速度、日距、温度、轴倾角、卫星数、本页动画周期，外加一条冷知识。由纯 CSS 的 `:has()` 选择器驱动，零 JavaScript；触屏点按、键盘 Tab 聚焦同样有效。
- 🎨 **分色轨道线**：每条轨道使用该行星的色相，hover 时统一提亮为白色。
- ✨ **双层星空**：`:before` / `:after` 两层星点以不同节奏 `starShimmer` 明暗交替，且都以太阳为中心。
- 📱 **响应式缩放**：`--scale` 变量 + 四档媒体查询整体等比缩放，小屏不再溢出或横滚。
- ⚡ **合成层优化**：轨道 div 加了 `will-change: transform` + `backface-visibility`，大圆环旋转交给 GPU。
- ♿ **无障碍**：支持 `prefers-reduced-motion`，系统开启「减弱动态效果」时自动停止所有动画。

### 二、404 星空页面（`404.html`）

**核心特性**

- ✨ **60 颗星星**：30 颗带光晕的闪烁流星（`star-1`）+ 30 颗小圆点星（`star-2`），位置随机、延迟错开（1s~5s），`twinkle` 动画交替明暗。
- 🌠 **渐变夜空**：`#292256 → #8446cf → #a871d6` 的紫色星云渐变，叠加径向暗角。
- 🌙 **会睡觉的月亮**：160px 发光月球，含闭眼、嘴巴打鼾（`snore` 缩放呼吸）与整体摇摆（`rotate` ±8°）动画，构成 `4 🌙 4` 标题。
- 🐦 **6 只 3D 飞鸟**：CSS 3D `transform-style: preserve-3d` + 四组翅膀关键帧（左右翼、翼尖）实现扇翅，各自拥有独立航线、景深与出场延迟。
- 🔤 **标题排版**：`Russo One` + `Lato` 字体，200px 巨型数字（带金属渐变，不支持时自动退回纯白）与文字阴影。
- 😴 **Zzz 打鼾气泡**：月亮头顶飘出三级递大的 `Z z z`，与呼吸节奏同步。
- 📱 **响应式适配**：`max-width: 580px` 时自动缩小数字（100px）、月亮（100px）与表情缩放；标题容器改为 `100%` 宽，不再溢出。
- 🔁 **可见倒计时**：页面显示「N 秒后自动返回首页…」，5 秒后跳转（`setInterval(refer, 1000)`，不再使用字符串 eval）。
- 🔘 **毛玻璃返回按钮**：`backdrop-filter` 半透明按钮，hover 上浮 + 发光；语义化为 `<a class="btn">`（原 `<a><button>` 嵌套已修正）。
- ♿ **无障碍**：支持 `prefers-reduced-motion`。
- 📄 **单文件自包含**：HTML + CSS + 极简 JS 全部内联在一个文件中，便于直接部署为 GitHub Pages / Nginx 的 404 页。

## 快速开始

**方式一：直接打开（推荐）**

```bash
# 双击即可，或用浏览器打开
index.html
```

**方式二：本地静态服务**

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```

**方式三：部署到 GitHub Pages**

1. 仓库 → **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后访问 `https://<用户名>.github.io/solar-syst/`

> GitHub Pages 会自动将 `404.html` 作为该站点的 404 错误页。

## 实现原理

1. **轨道 = 圆形 div**：每个天体是一个 `border-radius: 1000px` 的透明圆环（轨道线 `rgba(102,166,229,.12)`），通过 `top/left: 50%` 与负 `margin` 居中。
2. **天体 = 伪元素**：`::before` 是圆环顶部（`left: 50%`）的小圆点，即行星本体；`::after` 用于附加结构（月球的月球、土星的环）。
3. **公转 = 旋转父容器**：对轨道 div 施加 `animation: orb <周期> linear infinite`，行星随圆环一起绕中心旋转。
4. **星空 = box-shadow 点阵**：一个 2×2px 的伪元素，用上百组 `box-shadow: Xpx Ypx 0 0 rgba(255,255,255,α)` 复制出满天星，零 DOM 开销。
5. **土星环稳定**：土星 `::after` 使用 `animation-direction: reverse` 抵消父级旋转，使环面始终保持 52° 倾斜。

```css
/* 核心动画 */
@keyframes orb {
  from { transform: rotate(0deg); }
  to   { transform: rotate(-360deg); }
}
```

## 自定义与二次开发

- **调整整体速度**：只改 `css/style.css` 里 `:root` 的 `--earth-year`（默认 `30s`），所有天体周期由 `calc()` 自动换算（改成 `15s` 即 2 倍速）。
- **修改某颗行星**：编辑对应类的 `height/width`（轨道半径）、`::before` 的 `width/height/background`（星球大小与颜色）。
- **增删天体**：在 `index.html` 的 `.solar-syst` 中增删一个 `div`，并在 `css/style.css` 中补一段同名样式即可。
- **更换 404 跳转地址**：只需改 `404.html` 脚本里的 `var HOME = "..."`，返回按钮与倒计时共用这一个常量。
- **调整说明面板**：`index.html` 顶部的 `.description`（标题 + 说明 + `.legend` 图例）可直接改文案；图例色点由 `.dot-*` 类控制，尺寸/显隐见媒体查询。
- **修改数据卡内容**：`index.html` 底部的 `<aside class="info-panel">` 里，每个天体一个 `<section class="card card-xxx">`，改 `<dl>` 里的 `<dt>/<dd>` 即可；新增天体时在 CSS 里补一条 `body:has(.xxx:hover) .card-xxx { display: block; }`。

## 已知事项

- 太阳系为**示意性比例**：行星大小与轨道间距经过艺术化处理，非严格天文比例（按真实比例水星将小到不可见）。
- `404.html` 仍从 Google Fonts 加载 `Lato` / `Russo One`，已改为 `<link>` + `preconnect` + `display=swap`（不再阻塞渲染，且带系统字体兜底）；国内网络环境可按需改为本地资源或移除。
- 图例中的冥王星按矮行星处理，仅作示意保留。
- 小屏下说明面板会自动收起图例（`.legend { display: none }`），信息卡改为**贴底窄条**并隐藏冷知识行；触屏点按天体同样会触发卡片（`tabindex` + `:focus`）。
- 小屏为了塞下 780px 的最外轨道，整体要缩到 0.34~0.45 倍，因此用 `--boost` 对星球 / 土星环 / 月球做**尺寸补偿**（`--boost=1` 时与桌面完全一致）；若觉得补偿过度，改媒体查询里的 `--boost` 即可。
- **悬停数据卡依赖 CSS `:has()`**：需 Chrome 105+ / Edge 105+ / Safari 15.4+ / Firefox 121+（2023 年底起已是 Baseline）。旧浏览器只会退化成不显示卡片，页面其余部分不受影响。
- 悬停命中范围是「轨道圆盘」：光标落在两条轨道之间的空白时，会显示**外侧最近的那条轨道**所属天体，这是有意保留的行为（也让 3~4px 的水星、冥王星更好点中）。
- 天体数据取自 NASA Planetary Fact Sheet 的公开数值，卫星数量会随新发现变动（页面已用「95+」等方式标注）。
