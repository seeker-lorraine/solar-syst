## 项目简介

`solar-syst` 由两个相互独立的静态页面组成：

| 页面 | 说明 |
| --- | --- |
| `index.html` | 太阳系公转动画主页面：以太阳为中心，八大行星 + 冥王星 + 小行星带按真实周期比例环绕运行 |
| `404.html` | 纯 CSS 的 404 星空页面：会眨眼的星星、睡觉的月亮、扇动翅膀的 3D 小鸟 |

两个页面都**不依赖任何构建工具、框架与 JavaScript 运行时**（404 页仅有一段可选的自动跳转脚本），双击即可在浏览器打开。

## 功能总览

### 一、太阳系页面（`index.html`）

**核心特性**

- ⏱️ **真实时间比例公转**：以「地球公转一周 = 30 秒」为基准换算，各行星动画时长严格对应其真实公转周期（水星 7.19s ↔ 87.5 天，海王星 4911.78s ↔ 59802 天）。
- 🪐 **完整天体阵容**：太阳 + 水星、金星、地球、火星、木星、土星、天王星、海王星、冥王星 + 小行星带。
- 🌍 **地月系统**：地球自带一颗跟随公转的月球（`2.244s ↔ 27.32 天`）。
- 💍 **土星环**：倾斜 52° 的行星环，并反向旋转以保持环面朝向稳定。
- 🌌 **星空背景**：`radial-gradient` 深空底色 + 单个伪元素 `box-shadow` 绘制的 **300+ 颗随机星点**。
- ☄️ **小行星带**：位于火星与木星轨道之间，由数百个 `box-shadow` 点阵模拟的碎石带，独立旋转（≈6 年/圈）。
- 🔆 **光照立体感**：每颗行星使用 `inset box-shadow` 营造背光面阴影（晨昏线效果）。
- 🎨 **拟真配色**：每颗天体使用独立的渐变/实色（如木星 `#c76e2a`、天王星 `#b5e3e3`、冥王星 `#fff`）。
- ♾️ **无缝循环**：`orb` 关键帧 `rotate(0deg) → rotate(-360deg)`，`linear infinite` 匀速无缝衔接。
- 📐 **同心圆轨道**：所有天体以 `top/left: 50%` + 负 `margin` 精确定位，形成同心轨道体系。
- 🧩 **纯 CSS 驱动**：动画全部由 `@keyframes` 完成，主页面**零 JavaScript**。
- 🧱 **语义化结构**：每个天体一个 `div`，类名即天体名（`.mercury` / `.saturn` ...），便于扩展。
- 🔧 **预留样式**：CSS 中已内置 `.description`（说明面板）、`.links`、`.hide` 等通用样式，可直接接入文案/链接模块。

### 二、404 星空页面（`404.html`）

**核心特性**

- ✨ **60 颗星星**：30 颗带光晕的闪烁流星（`star-1`）+ 30 颗小圆点星（`star-2`），位置随机、延迟错开（1s~5s），`twinkle` 动画交替明暗。
- 🌠 **渐变夜空**：`#292256 → #8446cf → #a871d6` 的紫色星云渐变，叠加径向暗角。
- 🌙 **会睡觉的月亮**：160px 发光月球，含闭眼、嘴巴打鼾（`snore` 缩放呼吸）与整体摇摆（`rotate` ±8°）动画，构成 `4 🌙 4` 标题。
- 🐦 **6 只 3D 飞鸟**：CSS 3D `transform-style: preserve-3d` + 四组翅膀关键帧（左右翼、翼尖）实现扇翅，各自拥有独立航线、景深与出场延迟。
- 🔤 **标题排版**：`Russo One` + `Lato` 字体，200px 巨型数字与文字阴影。
- 📱 **响应式适配**：`max-width: 580px` 时自动缩小数字（100px）、月亮（100px）与表情缩放。
- 🔁 **自动跳转**：内置 10 × 500ms（≈5 秒）倒计时后自动返回主页。
- 🔘 **返回按钮**：带 hover 透明度过渡的描边按钮，可手动立即返回。
- 📄 **单文件自包含**：HTML + CSS + 极简 JS 全部内联在一个文件中，便于直接部署为 GitHub Pages / Nginx 的 404 页。

## 快速开始

**方式一：直接打开（推荐）**

```bash
# 双击即可，或用浏览器打开
index.html
```

**方式二：本地静态服务**

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```

**方式三：部署到 GitHub Pages**

1. 仓库 → **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后访问 `https://<用户名>.github.io/solar-syst/`

> GitHub Pages 会自动将 `404.html` 作为该站点的 404 错误页。

## 实现原理

1. **轨道 = 圆形 div**：每个天体是一个 `border-radius: 1000px` 的透明圆环（轨道线 `rgba(102,166,229,.12)`），通过 `top/left: 50%` 与负 `margin` 居中。
2. **天体 = 伪元素**：`::before` 是圆环顶部（`left: 50%`）的小圆点，即行星本体；`::after` 用于附加结构（月球的月球、土星的环）。
3. **公转 = 旋转父容器**：对轨道 div 施加 `animation: orb <周期> linear infinite`，行星随圆环一起绕中心旋转。
4. **星空 = box-shadow 点阵**：一个 2×2px 的伪元素，用上百组 `box-shadow: Xpx Ypx 0 0 rgba(255,255,255,α)` 复制出满天星，零 DOM 开销。
5. **土星环稳定**：土星 `::after` 使用 `animation-direction: reverse` 抵消父级旋转，使环面始终保持 52° 倾斜。

```css
/* 核心动画 */
@keyframes orb {
  from { transform: rotate(0deg); }
  to   { transform: rotate(-360deg); }
}
```

## 自定义与二次开发

- **调整整体速度**：统一缩放所有 `animation: orb Xs` 的秒数（如全部 ×0.5 = 2 倍速）。
- **修改某颗行星**：编辑对应类的 `height/width`（轨道半径）、`::before` 的 `width/height/background`（星球大小与颜色）。
- **增删天体**：在 `index.html` 的 `.solar-syst` 中增删一个 `div`，并在 `css/style.css` 中补一段同名样式即可。
- **更换 404 跳转地址**：替换 `404.html` 中的跳转地址（共 2 处：返回按钮的 `href` 与倒计时脚本中的 `location.href`），改为自己的站点地址。
- **接入说明文案**：`index.html` 中加入 `<div class="description">...</div>` 即可使用 CSS 中预留的说明面板样式。

## 已知事项

- `index.html` 的 `<title>` 目前为「加载」，可按需改为「太阳系」等。
- `index.html` 引入了 Google Fonts（Lato）与 Font Awesome 4.2.0，当前页面未直接使用，属于预留依赖；国内网络环境可考虑改为本地资源或移除。
- `404.html` 的返回按钮与自动跳转目标为硬编码地址（共 2 处），更换站点时需同步修改。
- 太阳系为**示意性比例**：行星大小与轨道间距经过艺术化处理，非严格天文比例。
